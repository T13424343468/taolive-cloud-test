# 道映手机版 · 使用说明

> 本文档随完整包交付；标注〔出包填〕的数字在出包时定稿。

## 一、这是什么

道映手机版是 TaoLive 直播的 Android 手机端（64 位 arm64），面向一加 15T / ACE5 等现代机型。直播内核与 TaoPlay 家底同源，界面沿用老电视风格，并内置 AI 实时画质优化（与 TaoPlay 同一套 TaoAI 链路：模型文件、图标、素材全部沿用，仅按直播分片适配）。

- 版本：versionCode 〔出包填〕 / versionName 〔出包填〕
- 包名：com.taolive.phone
- 架构：arm64（64 位）
- APK SHA-256：〔出包填〕

## 二、安装与首次启动

1. 将安装包传入手机，点击安装（如系统提示未知来源，允许该来源安装）。
2. 首次启动进入频道列表页；直接点台名即开播。
3. 建议在系统设置中允许「后台弹出界面」与电池不优化，提升切后台返回的重接体验。

## 三、频道列表页

- 顶部筛选框：输入频道号（数字）或台名关键字（文字），数字与文字可混合，边输边筛；命中后点一下即跳台。
- 台标、分类沿用电视版同款口径；目录含央视/卫视/地方台共 112 路（v22 挂链口径）。

## 四、播放页功能

### 沿用功能（与 TaoPlay 手机版同款）

- 单击呼出/收起控制条；控制条 1.2 秒自动收起
- 上台 / 下台切换（底部控制条左右钮，直播切台）
- 暂停 / 播放（中央浮钮同步真实状态）
- 左侧上下滑调亮度、右侧上下滑调音量（屏幕中央有提示胶囊）
- 锁定：锁定后手势与呼出全失效，解锁键点屏幕时亮 2.5 秒，返回键需两次确认防误退
- 画中画（更多菜单入口；按画面宽高比设置窗口）

### 明确不做（老板拍板砍件）

- 倍速（含长按 3x 快进）
- 数字换台 OSD
- 进度条 / 拖动预览浮层
- 横滑快进退

直播为实时直出，无进度概念；换台入口在频道列表页顶部筛选框。

## 五、AI 实时画质优化

- 分片到手立即 AI 接管按段加工，加工完放行播放，可接受 1 分钟内延迟。
- 初始缓冲目标 15 秒（口径区间 10–20 秒）；落后上限 60 秒封顶。
- 三道保险：
  1. 加工追不上 → 自动降档建议；
  2. 过热 / 低电 → 退回原画质直出；
  3. 延迟达 60 秒封顶 → 强制直出并锁定延迟，换台后复位恢复。
- 真机试跑台账（哪些台吃满 4K、哪些自动降档）在验收后另行汇报。

## 六、直播源说明

- 全部为免费直连源，不涉及任何加密保护。
- 免费公共源按天腐化属正常现象：某台黑屏/加载失败时，优先怀疑源侧而非软件；可换台重试或等待换源。
- 遇运营商限流提示时，App 会按同一本退避账给出动态预期（如「约 X 分钟后自动重试」）。

## 七、故障排查速查

| 现象 | 先查 |
| --- | --- |
| 黑屏不出画面 | 换一台试试——多台皆黑再报问题；单台黑多为源腐化 |
| 提示限流/退避 | 按提示等待自动重试，退避期内 App 不发起请求 |
| 返回后重接慢 | 切后台返回后数秒内自动重接为预期行为 |
| 画质提示降档 | AI 保险动作：过热/低电或加工速率不足时退直出，降档提示属正常 |
